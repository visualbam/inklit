About Inklit

Inklit is a terminal-first dashboard for coordinating AI coding agents as they work in isolated git worktrees.

What it does

The project keeps parallel agent tasks visible, reviewable, and scoped. Each task can run in its own worktree while the dashboard tracks status, changed files, diffs, logs, and merge readiness from one compact TUI.

Why it exists

Working with multiple agents is most useful when the workflow stays organized. Inklit focuses on giving developers a clear task board, keyboard-driven controls, and explicit review steps before work is applied back to the main checkout.

Highlights

  • Runs as an Ink/React terminal UI for fast keyboard navigation.
  • Uses worktrunk's wt CLI for git worktree management.
  • Opens agent sessions in zellij and tmux for focused follow-up.
  • Keeps review, apply, archive, and kill workflows explicit.
